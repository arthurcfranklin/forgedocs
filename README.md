# ForgeDocs

ForgeDocs é uma suíte desktop para Windows focada na manipulação de documentos com processamento 100% local.

## Objetivos

- Conversão de documentos
- Organização de PDFs
- Otimização
- OCR
- Segurança
- Assinatura digital

## Tecnologias

- Python
- CustomTkinter
- PyMuPDF
- Pillow
- python-docx
- openpyxl
- python-pptx
