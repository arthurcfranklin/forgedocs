# Diretrizes de Interface (UI Guidelines)

## Objetivo

Este documento define os padrões visuais do ForgeDocs.

O objetivo é garantir consistência entre todas as telas da aplicação, proporcionando uma experiência moderna, intuitiva e profissional.

Todas as novas páginas e componentes deverão seguir estas diretrizes.

---

# Filosofia

O ForgeDocs deve transmitir:

- simplicidade;
- clareza;
- produtividade;
- profissionalismo;
- confiança.

A interface deve priorizar a execução das tarefas, evitando distrações e excesso de elementos visuais.

---

# Estilo visual

O ForgeDocs utilizará uma identidade visual inspirada em aplicações desktop modernas.

Referências:

- Visual Studio Code
- Notion Desktop
- Microsoft Loop
- PDFgear
- PDF-XChange Editor
- Obsidian

Características:

- interface limpa;
- alto contraste;
- poucos elementos decorativos;
- foco no conteúdo.

---

# Tema padrão

Tema inicial:

Dark Mode

O suporte ao Light Mode poderá ser implementado futuramente.

---

# Paleta de cores

## Fundo principal

Cor predominante escura.

Responsável por:

- janela principal;
- páginas;
- área de trabalho.

---

## Sidebar

Levemente diferente do fundo principal para facilitar a separação visual.

---

## Cards

Devem possuir:

- cantos arredondados;
- leve contraste;
- espaçamento interno consistente.

---

## Cor primária

Utilizada para:

- botões principais;
- ações positivas;
- destaques;
- seleção.

---

## Cores de Status

Sucesso: **Verde**

Aviso: **Amarelo**

Erro: **Vermelho**

Informação: **Azul**

---

# Tipografia

Fonte padrão: **Sistema operacional**

### Hierarquia:

Título: **Maior destaque**

Subtítulo: **Intermediário**

Texto: **Leitura confortável**

Legenda: **Menor tamanho**

---

# Espaçamentos

Utilizar espaçamentos consistentes.

Recomendações:

- margem externa uniforme;
- distância fixa entre componentes;
- alinhamentos em grade.

---

# Ícones

Todos os ícones devem pertencer ao mesmo conjunto visual.

Evitar misturar estilos diferentes.

---

# Sidebar

A sidebar será responsável pela navegação principal.

Itens previstos:

- Início
- Conversão
- Organização
- Otimização
- OCR
- Segurança
- Configurações

Características:

- largura fixa;
- ícones;
- texto;
- destaque da página ativa.

---

# Cabeçalho

Cada página deverá possuir um cabeçalho contendo:

- título;
- descrição;
- ações específicas (quando necessário).

---

# Componentes

Componentes reutilizáveis previstos:

- botão;
- botão de navegação;
- card;
- seletor de arquivos;
- barra de progresso;
- caixa de diálogo;
- painel de notificações;
- barra de status.

---

# Botões

Todos os botões devem possuir:

- efeito hover;
- estado desabilitado;
- cursor apropriado;
- feedback visual ao clique.

---

# Campos de entrada

Devem apresentar:

- placeholder;
- validação;
- mensagens claras de erro.

---

# Diálogos

Utilizar diálogos para:

- confirmação;
- erros;
- sucesso;
- seleção de arquivos.

Evitar janelas desnecessárias.

---

# Barra de progresso

Operações demoradas deverão informar:

- progresso;
- etapa atual;
- possibilidade de cancelamento quando aplicável.

---

# Responsividade

Embora seja uma aplicação desktop, a interface deverá adaptar-se adequadamente ao redimensionamento da janela.

Evitar sobreposição de componentes.

---

# Acessibilidade

Sempre que possível:

- alto contraste;
- textos legíveis;
- ícones compreensíveis;
- navegação intuitiva.

---

# Consistência

Todo novo componente deverá seguir estas diretrizes.

A identidade visual deve permanecer uniforme em toda a aplicação.

---

# Revisões

Este documento poderá evoluir conforme novas necessidades forem surgindo durante o desenvolvimento do ForgeDocs.
